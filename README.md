# Astro Places Client Releases

This repository is dedicated to hosting the compiled releases and updates for the Astro Places chat client. The source code for the client is proprietary and maintained in a separate private repository.

## About the Project

Astro Places is a desktop chat client inspired by Ubique Virtual Places, specifically drawing heavy inspiration from Excite Virtual Places. The goal of this project is to recreate the feel of those classic avatar based chat environments for modern systems.

## Downloading the Client

You do not need to download or clone this repository to use the software. 

To get the latest version of the client:
* Navigate to the Releases section on the right side of this page.
* Click on the latest release tag.
* Download the Setup executable file attached to the release.
* Run the installer to install the client on your system.

## Updates

The Astro Places client includes a built in auto update feature. Once you have installed the client for the first time, it will automatically check this repository for new releases on startup and apply any available updates in the background.

## Support and Feedback

If you encounter any bugs or have feature requests, please submit an issue through the Issues tab of this repository. Include the following information when submitting a report:
* The version number of the client you are currently using.
* Your operating system.
* A detailed description of the problem or request.
